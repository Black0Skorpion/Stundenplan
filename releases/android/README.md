# Android-App

Alle Versionen der Stundenplan-App als `.apk`. Die höchste Versionsnummer ist die neueste.

Installieren: Datei auf dem Handy herunterladen (auf die Datei tippen → „Download“/„View raw“),
öffnen und installieren – Installation aus unbekannten Quellen erlauben.
Ab **1.4** sind alle Versionen mit demselben festen Schlüssel signiert: neue Versionen einfach
drüber installieren, Einstellungen bleiben erhalten. Beim Wechsel von 1.0–1.3 auf 1.4 muss die alte
App einmalig deinstalliert werden (die alten Versionen hatten bei jedem Build einen anderen Test-Schlüssel).
