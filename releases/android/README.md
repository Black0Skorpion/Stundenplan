# Android-App

Alle Versionen der Stundenplan-App als `.apk`. Die höchste Versionsnummer ist die neueste.

Installieren: Datei auf dem Handy herunterladen (auf die Datei tippen → „Download“/„View raw“),
öffnen und installieren – Installation aus unbekannten Quellen erlauben.
Neue Versionen einfach drüber installieren, Einstellungen bleiben erhalten.
