# Scriptable-Skripte (iPhone/iPad)

Alle Versionen der Skripte für die App [Scriptable](https://scriptable.app), je Version ein Ordner.
Die höchste Versionsnummer ist die neueste; die aktuelle Fassung liegt auch in [`scriptable/`](../../scriptable).

| Datei | Inhalt |
|---|---|
| `Stundenplan.js` | Stundenplan-Widgets (klein bis extragroß, Sperrbildschirm), Lageplan, Einstellungen, Siri |
| `AbfahrtenGolm.js` | Abfahrten am Campus (Name bleibt aus Kompatibilität „Golm“) |
| `MensaGolm.js` | Mensa am Campus |

**Installieren**
- **Am PC:** Datei herunterladen (Datei anklicken → „Download raw file“) und in
  iCloud Drive › Scriptable legen. Gleichnamige Dateien einfach ersetzen.
- **Am iPhone:** Datei öffnen → „Raw“ → Text kopieren → in Scriptable ein Script mit **genau dem
  gleichen Namen** anlegen bzw. öffnen und den Inhalt ersetzen.

Die Dateinamen nicht ändern: Widgets merken sich das Script über den Namen.
Jede Version gibt es auch als [Release](https://github.com/Black0Skorpion/Stundenplan/releases)
(Tag `scriptable-v…`, mit allen drei Dateien und als ZIP).
