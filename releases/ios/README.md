# iOS-App (iPhone/iPad)

Alle Versionen der Stundenplan-App als `.ipa`. Die höchste Versionsnummer ist die neueste.

Installieren (ohne bezahlten Apple-Developer-Account):
- **PC:** [iloader](https://github.com/nab138/iloader) → „IPA importieren“ → Datei auswählen.
- **iPhone:** SideStore → „My Apps“ → „+“ → Datei auswählen (LocalDevVPN an).

Kostenlos signiert läuft die App 7 Tage und muss dann neu installiert bzw. erneuert werden.
Neue Versionen einfach drüber installieren – Widgets und Einstellungen bleiben erhalten.
